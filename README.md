# 비석 글자 추출기

**POP 4 (Revopoint) 3D 스캐너로 스캔한 비석에서 음각·양각 글자를 추출하는 Windows 프로그램입니다.**

Revo Scan에서 내보낸 스캔 파일을 열면, 돌 표면의 아주 작은 깊이 차이를 이용해 글자를 찾아내고
다음 결과물을 **실제 크기(1:1)** 로 만들어 줍니다.

| 결과물 | 형식 | 쓰임 |
|---|---|---|
| 탁본 이미지 | PNG / TIFF | 종이 탁본처럼 보이는 흑백 이미지 (DPI 포함, 100% 인쇄 시 실제 크기) |
| 음영 기복 / 글자 강조 / 깊이 색상 | PNG / TIFF | 마모된 글자 판독용 |
| 흑백 글자 | PNG / TIFF | 글자만 검게 뽑은 이미지 |
| 벡터 외곽선 | SVG / DXF (mm) | 일러스트레이터·CAD에서 편집 |
| 글자 3D 모델 | PLY / OBJ | 원본 스캔에서 글자 부분만 잘라낸 기록용 모델 |
| 3D 프린팅 모델 | STL (닫힌 메쉬) | 글자판 / 입체 글자 / 비석 표면 복제 |
| 판독문 | 텍스트 | 오프라인 OCR(한자·영문, 한글) 또는 AI 판독(Claude) |

---

## 1. 설치하기

### 방법 A. 실행 파일 (가장 쉬움, 추천)

1. 이 저장소의 GitHub 페이지에서 **Actions** 탭 → 가장 최근의 초록색 체크(✔) 실행 → 아래쪽 **Artifacts** 의
   `SteleExtractor-windows` 를 내려받습니다. (릴리스가 있으면 **Releases** 에서 `SteleExtractor-windows.zip` 을 받아도 됩니다.)
2. 받은 zip 파일을 마우스 오른쪽 버튼 → **압축 풀기** 합니다. (예: `문서\SteleExtractor`)
3. 폴더 안의 **`SteleExtractor.exe`** 를 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누르세요. (서명되지 않은 프로그램이라 나오는 안내입니다)
   - 폴더 안의 다른 파일은 지우지 마세요. 폴더째로 옮기는 것은 괜찮습니다.

### 방법 B. Python으로 실행 (코드를 고쳐 쓰고 싶을 때)

1. [python.org](https://www.python.org/downloads/) 에서 **Python 3.11** 을 설치합니다.
   설치 첫 화면에서 **"Add python.exe to PATH"** 를 꼭 체크하세요.
2. 이 저장소를 내려받아 압축을 풉니다 (GitHub 페이지의 **Code → Download ZIP**).
3. 폴더 안의 **`run.bat`** 을 더블클릭합니다.
   처음 한 번은 필요한 구성요소를 설치하느라 몇 분 걸립니다. 다음부터는 바로 실행됩니다.

## 2. 스캔 준비 (Revo Scan)

- POP 4로 비석을 스캔한 뒤 Revo Scan에서 **메쉬(Mesh)** 를 만들고 **PLY** 로 내보내는 것을 권장합니다.
  (OBJ, STL도 됩니다. 점군(Point Cloud) PLY도 열 수 있지만 3D 잘라내기는 메쉬만 됩니다.)
- 색상(텍스처)을 켜고 내보내면 [색상 보조] 기능을 쓸 수 있습니다.
- 글자 면을 정면에서 고르게 스캔할수록 결과가 좋습니다. 비석 한 면 전체를 여러 번 나눠 스캔했다면
  Revo Scan에서 **병합(Merge)** 한 뒤 내보내세요.
- 단위는 Revo Scan 기본값인 **mm** 그대로 두면 됩니다.

## 3. 사용법

### 3-1. 열기
- **[스캔 열기]** 로 파일을 엽니다. 파일을 창으로 끌어다 놓아도 됩니다.
- 스캔이 없으면 **[가상 비석 만들기]** 로 시험용 데이터를 만들어 연습할 수 있습니다.

열면 자동으로 처리되어 **[2D 결과]** 탭에 탁본이 나타납니다. 위쪽 **[보기]** 목록에서 결과 종류를 바꿉니다.
마우스 휠 = 확대/축소, 끌기 = 이동.

### 3-2. 보정 (오른쪽 [설정] 패널)

| 상황 | 해결 |
|---|---|
| 글자가 옆으로/거꾸로 보임 | **[회전]** ↺ ↻ 버튼 (또는 판독 후 "방향 맞추기"에 [예]) |
| 글자가 살짝 기울어짐 | **[기울기 자동 보정]** 을 켜 둡니다 (기본값) |
| 음각인데 솟아 보이거나 반대 | **[앞뒤 뒤집기]** |
| 둥근 비석이라 가장자리 글자가 찌그러짐 | **[표면 형태] → 원통 펼치기** (보통 자동 판단으로 충분) |
| 얕은 글자가 흑백 결과에서 빠짐 | **[감도]** 를 올림 |
| 돌 표면의 잡티가 글자로 잡힘 | **[최소 크기]**, **[잡음 제거]** 를 올림, [감도]를 내림 |
| 큰 굴곡·얼룩 때문에 결과가 고르지 않음 | **[배경 제거]** 의 [자동]을 끄고 글자 크기의 1~2배로 맞춤 |
| 글자에 색이 칠해져 있음 | **[색상 보조]** 를 올림 |
| 마모가 심해 잘 안 보임 | [보기 → 음영 기복] 에서 **[빛 방향]** 을 돌려 가며 확인 |

**[영역 선택]** 을 누르고 2D 화면에서 사각형을 끌면 그 부분만 처리합니다. **[전체 영역]** 으로 되돌립니다.
화면 아래에 마우스 위치(mm)와 그 지점의 높이(mm)가 표시됩니다.

### 3-3. 내보내기 ([파일] 메뉴 또는 도구 모음)
- **이미지 내보내기**: 원하는 이미지를 골라 PNG/TIFF로 저장합니다. mm 눈금자를 붙일 수 있고,
  이미지에 DPI가 들어 있어 **100% 크기로 인쇄하면 실제 크기**와 같습니다.
  깊이 값 TIFF(32비트, mm 단위)와 처리 정보(JSON)도 함께 저장됩니다.
- **벡터 외곽선 내보내기**: SVG(일러스트레이터·잉크스케이프), DXF(오토캐드 등). 단위 mm, 1:1.
  DXF는 `LETTERS`(글자 바깥선), `HOLES`(글자 안쪽 구멍), `FRAME`(영역 테두리) 레이어로 나뉩니다.
- **글자 3D 모델 내보내기**
  - *원본 스캔에서 글자 부분만 잘라내기*: 실제 표면 그대로 (PLY/OBJ, 색상 포함)
  - *글자판*: 바닥판 위에 글자가 솟은 판, 또는 글자를 파낸 판 (STL)
  - *글자만*: 외곽선을 위로 밀어 올린 입체 글자 (STL)
  - *표면 복제*: 비석 표면의 굴곡을 살린 판, 높이 배율 조절 가능 (STL)
  - *좌우 반전*: 도장처럼 찍어 낼 틀을 만들 때

  프린팅용 STL은 모두 닫힌(watertight) 메쉬라 슬라이서에서 바로 쓸 수 있습니다.

### 3-4. 글자 판독 (오른쪽 [글자 판독] 패널)
- **오프라인 OCR** (무료, 인터넷 불필요)
  - *한자·영문*: 프로그램에 들어 있는 모델
  - *한글*: 처음 한 번 **[한국어 모델 내려받기]** (약 4MB, 인터넷 필요)
  - *쓰기 방향*: 세로쓰기(오른쪽 열부터) / 가로쓰기
  - *글자 방향 자동 찾기*: 90°씩 돌려 가며 가장 잘 읽히는 방향을 고릅니다.
  - 깨끗한 글자는 잘 읽지만, 마모되거나 옛 글자는 틀리기 쉽습니다.
- **AI 판독** (Claude)
  - 마모된 글자, 옛 한자, 이체자 판독에 강하고 풀이도 함께 받을 수 있습니다.
  - **[파일 → 설정]** 에서 Anthropic API 키를 넣어야 합니다
    ([console.anthropic.com](https://console.anthropic.com) 에서 발급, 사용한 만큼 요금 부과).
  - [참고 정보]에 "조선 후기 묘비, 한문 세로쓰기" 같이 적으면 더 정확해집니다.
- 판독 결과는 직접 고칠 수 있고, 판독 기록은 프로젝트에 저장됩니다.
  **[읽은 위치 보기]** 로 OCR이 어느 줄/열을 읽었는지 확인할 수 있습니다.

> AI 판독도 틀릴 수 있습니다. 최종 판독은 반드시 사람이 확인하세요.

### 3-5. 프로젝트 저장
**[프로젝트 저장]** 을 하면 비석별 폴더가 만들어집니다.

```
비석이름/
  project.json   설정, 선택 영역, 비석 정보, 판독 결과
  scan/          원본 스캔 복사본 (선택)
  결과/          내보낸 파일 (기본 저장 위치)
  미리보기.png
```

**[비석 정보]** 에 이름·위치·조사 날짜·조사자·메모를 적어 둘 수 있습니다.
**[프로젝트 열기]** 로 `project.json` 을 열면 저장할 때 상태 그대로 돌아옵니다.

## 4. 처리 원리 (간단히)

1. **펼치기**: 스캔 점들에 가장 잘 맞는 평면(또는 원통)을 찾아 비석 면을 종이처럼 펼칩니다.
   원통 펼치기를 쓰면 둥근 면도 실제 길이 그대로 펴집니다.
2. **높이 지도**: 펼친 면을 일정한 간격(mm/픽셀)의 격자로 만들어 각 칸의 높이를 구합니다.
3. **배경 제거**: 비석의 큰 굴곡과 기울기를 빼서 글자 깊이(보통 0.3~3mm)만 남깁니다.
   글자 부분은 배경 계산에서 빼므로 글자 깊이가 줄어들지 않습니다.
4. **글자 신호**: 음각/양각을 자동 판단해 "얼마나 파였는지(솟았는지)"를 계산하고,
   필요하면 색상 정보를 섞습니다.
5. **흑백 글자**: 자동 임계값(Otsu)과 [감도]로 글자 영역을 정하고 작은 잡티를 지웁니다.
6. 이 결과로 탁본·음영 이미지, 벡터 외곽선, 3D 모델, OCR 입력을 만듭니다.

## 5. 문제 해결

- **3D 보기 탭이 비어 있거나 오류 문구가 나와요** → 그래픽 드라이버 문제입니다. 2D 결과와 모든 내보내기는 그대로 쓸 수 있습니다.
  그래픽 드라이버를 최신으로 업데이트해 보세요.
- **"해상도가 너무 높습니다"** → [해상도]의 [자동]을 끄고 mm/픽셀 값을 크게(예: 0.3) 하세요.
- **처리가 느려요** → 아주 큰 스캔은 [해상도] 값을 키우거나 [영역 선택]으로 필요한 부분만 처리하세요.
- **파일 단위가 이상해요 (아주 작거나 큼)** → [설정 → 파일 단위]를 mm / cm / m 중에서 맞게 고르세요.
- **한국어 모델 내려받기 실패** → 인터넷 연결을 확인하세요. 회사·학교망에서는 막힐 수 있습니다.

## 6. 개발자용

```bash
pip install -r requirements-dev.txt
python -m pytest            # 시험 (가상 비석 데이터 사용)
python -m stele_extractor   # 실행
python -m stele_extractor --selftest   # 화면 없이 기능 점검
pyinstaller --noconfirm SteleExtractor.spec   # 실행 파일 만들기 → dist/SteleExtractor/
```

GitHub에 올리면 Actions(`.github/workflows/build-windows.yml`)가 Windows에서 시험 → 실행 파일 빌드 →
자체 점검 → zip 묶음까지 자동으로 합니다. `v1.0.0` 같은 태그를 올리면 Releases에 zip이 올라갑니다.

### 폴더 구조

```
stele_extractor/
  core/            계산 (화면과 무관, 시험 가능)
    scan.py        스캔 파일 읽기 (PLY/OBJ/STL)
    surface.py     평면/원통 펼치기, 높이 지도
    relief.py      배경 제거, 글자 신호, 탁본·음영 이미지, 흑백화
    pipeline.py    전체 처리 흐름과 설정값
    export.py      이미지 저장 (DPI, 눈금자, 정보 JSON)
    vector.py      SVG/DXF 외곽선
    model3d.py     글자 3D 모델 (잘라내기, 프린팅용 STL)
    ocr.py         오프라인 OCR, AI 판독
    project.py     프로젝트 저장/열기
    synthetic.py   가상 비석 데이터
  gui/             화면 (PySide6)
tests/             자동 시험
```
